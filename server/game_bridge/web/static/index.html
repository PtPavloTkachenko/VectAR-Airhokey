How to play

1 · Pair your Vector (tab above) — the Bluetooth path sets it up, no typing.
2 · Put Vector on a table with ~1 m of free space, robot connected (green).
3 · Open the lens in Lens Studio and send it to Spectacles — no address to set, it finds this Mac by name. (Only if your headset can't resolve .local: put the literal address from the "Lens WS_URL" card into GameConfig.WS_URL.)
4 · Calibrate the surface with your hand, place Vector on the glowing mark, press START.

Project status

The full chain — Spectacles → this server → a real Vector driving — has been demonstrated end-to-end in two earlier builds: this air-hockey game, and the first version of VectAR OS (the wider robot + AR + AI system it grew alongside). The goalie drove, blocked and talked. That capability isn't the open question.

What's in progress is deliberate: the test robot was factory-reset on purpose to build the out-of-the-box path — what setting up a robot from scratch actually looks like. The goal is to automate that onboarding: turn a day of manual SSH, certs, cloud config and token wrangling into a few clicks, so this and future robot projects get a Vector online in minutes.

Spectacles ↔ this server — verified live on device: surface calibration, AR field, puck physics, scoring.
Stock robot, out of the box → authorized — verified end-to-end on hardware (2026-07-25): Bluetooth pairing, PIN, Wi-Fi, the escape-pod firmware install, the robot's sign-in to the pairing engine, and minting this Mac's control token. Nothing is typed by hand and the Vector app is never needed.

Setup, per robot type — two independent tracks:
· Stock — verified end-to-end, as above. The firmware install is a real OTA: he downloads ~180 MB himself and reboots — keep him on the charger and don't interrupt.
· OSKR / dev — the SSH and log-archive routes are implemented but not yet re-verified on current hardware; this is the remaining open track.

Details: docs/STOCK_ONBOARDING_PLAN.md (how the stock path works) and docs/SETUP_ROBOT.md → Status & risks.

Set up an OSKR / dev Vector

Dev robots grant access with their own SSH key, which lives inside their logs. Get his logs from Anki's official setup app, then drop the file here — we find the key and set him up for you.
1 Put Vector on his charger and double-press the back button until his face shows a setup screen.
2 Open vector-web-setup.anki.bot in Chrome and connect to Vector (it pairs over Bluetooth).
3 Choose Save Logs (a vector-logs-….tar.bz2 downloads).
4 Come back here and drop that file below.
